# Neo chess pieces

Original 300 x 300 transparent PNG pieces downloaded from Chess.com's theme CDN at the user's request, matching the supplied board reference. All twelve originals are kept locally.

Source pattern: https://images.chesscomfiles.com/chess-themes/pieces/neo/300/wp.png
The file name uses w/b followed by p/n/b/r/q/k.

Copyright Chess.com. These images are separate from the Cburnett GPL SVG set retained one directory above for the existing screenshot-recognition fixtures.
