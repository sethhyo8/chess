# Chess.com brand resources

Downloaded from the user-requested brand resource page:
https://www.chess.com/article/view/chess-com-brand-resources

The source URLs and descriptions are recorded in sources.json. The PNG originals are retained at their provided resolution (360 px sidebar assets; 2000 px classification assets) and displayed at interface sizes using normal image resampling.

These assets remain owned by Chess.com. They are separate from the application's original code and GPL-licensed pieces. Chessgrove is an independent application and does not use Chess.com's logo or claim affiliation.
